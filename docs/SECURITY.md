# Security review and limits

Completed: SQL values use bound parameters; admin DOM uses `textContent`; Worker HTML escapes member fields; verification and access tokens use cryptographic randomness and SHA-256 hashes at rest; tokens expire after 24 hours and confirmation is POST-only. Sessions use HttpOnly, Secure, SameSite=Lax cookies. Public writes require exact Origin and Cloudflare rate-limit binding. Admin routes require a secret bearer token held only in page memory. Multipart bodies are capped before parsing and audio signatures are checked. R2 keys are random, private and never public URLs. D1 unique constraints and an immutable, nonnegative ledger guard duplicate credits and spending.

Worker headers include no-store, no-referrer, nosniff, frame deny and a Permissions Policy. The verification and Worker-hosted member pages also set CSP. GitHub Pages cannot set arbitrary response headers through this repository; static pages use a referrer meta tag and no private data. Worker-only headers must be checked on the deployed Worker. Third-party Google Fonts are loaded only on the public pages; verification links load no third-party resources.

Residual limits: founder token is a shared bearer secret rather than individual accounts or MFA. Consider Cloudflare Access before scale. Cloudflare's configured rate limit is a coarse 5 requests/60 seconds; abuse may require Turnstile and operational monitoring. Email/phone are weak identity signals, and phone is not verified. R2 and D1 cannot commit atomically; a failure during multi-object deletion may require manual recovery. Local SQLite serializes test calls and cannot prove D1 behavior under distributed concurrency; perform controlled remote smoke tests before activation. Backup copies may outlive active record deletion. No independent penetration test, healthcare compliance assessment or legal approval has been completed.

Never place credentials in HTML, GitHub Actions variables exposed to the frontend, URLs, issues or comments. Rotate `ADMIN_TOKEN` and `RESEND_API_KEY` in Cloudflare if exposed. Keep R2 public access disabled.
